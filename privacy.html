Privacy Policy

Last updated: November 11, 2026

The Strange Origins Uploader is a private, single-user tool. It is used only by the owner of the Strange Origins YouTube channel to upload that owner's own videos.

Data accessed

With the owner's permission, the tool uses the YouTube Data API to upload videos, set titles, descriptions, tags and thumbnails, and read the owner's channel name. It does not access any other user's data.

Storage

The Google sign-in token is stored only on the owner's own computer. No data is sold, shared, or sent to any third party.

Google API compliance

Use of information received from Google APIs adheres to the Google API Services User Data Policy. This tool uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
